# OpenRay Balanced — multi-source + INCY

Одна автоматически обновляемая подписка для INCY. Workflow собирает узлы из
нескольких публичных репозиториев, удаляет дубликаты, выполняет реальную
end-to-end HTTPS-проверку через каждый узел и оставляет до 5 самых быстрых
рабочих узлов на страну.

## Подписка для INCY

```text
https://raw.githubusercontent.com/s49621471-lang/openray-balanced/main/balanced_incy.json
```

В INCY для каждой доступной страны создаются:

- `🇩🇪 Германия AUTO` — автоматически выбирает самый быстрый доступный узел;
- `🇩🇪 Германия #1`, `#2`, ... — ручной выбор проверенных узлов.

Названия и флаги формируются автоматически для всех ISO-стран. Если в стране
работает меньше 5 узлов, остаётся фактическое количество. Если не работает ни
один, страна исчезает до следующего успешного обновления.

## Обновление и проверка

Workflow запускается автоматически дважды в час (`:12` и `:42`) и вручную из
GitHub Actions. Проверка выполняется через Mihomo: запрос к HTTPS-адресу должен
реально пройти через конкретный прокси. После этого Xray проверяет синтаксис
каждой полной конфигурации INCY.

Результаты:

- `balanced_incy.json` — основная подписка INCY;
- `incy_stats.json` — страны, число физических узлов и конфигураций;
- `balanced.txt` / `balanced_base64.txt` — универсальная URI-подписка;
- `health_report.json` — результаты проверок;
- `sources.json` — состояние источников.

Публичный узел может перестать отвечать между запусками или блокироваться
конкретным провайдером. В таком случае на следующем обновлении он заменяется
следующим рабочим узлом той же страны; если замены нет, количество уменьшается
или страна временно пропадает.
