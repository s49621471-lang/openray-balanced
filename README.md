# OpenRay Balanced 5

Автообновляемая подписка: максимум 5 проверенных OpenRay-нод на каждую доступную страну.

## Что делает
- раз в час читает `OpenRay/output/country`;
- автоматически видит новые/исчезнувшие страны;
- берёт до 5 нод на страну;
- предпочитает разные протоколы;
- оставляет только VLESS / VMess / Trojan / Shadowsocks / Hysteria2;
- собирает `balanced.txt` и `balanced_base64.txt`.

OpenRay сам заявляет многоступенчатую проверку и почасовое обновление. Это означает
"рабочие по последней проверке OpenRay", но конкретный узел всё равно может быть
недоступен у отдельного оператора/провайдера.

## Как запустить
1. Создай публичный GitHub-репозиторий.
2. Загрузи всё содержимое этого ZIP в корень репозитория, включая `.github`.
3. Открой Actions -> "Update balanced OpenRay subscription" -> Run workflow.
4. После первого запуска используй в INCY:

   https://raw.githubusercontent.com/ТВОЙ_ЛОГИН/ИМЯ_РЕПО/main/balanced.txt

Если INCY ожидает base64-подписку, используй:

   https://raw.githubusercontent.com/ТВОЙ_ЛОГИН/ИМЯ_РЕПО/main/balanced_base64.txt

`stats.json` показывает число стран и нод после каждого обновления.
